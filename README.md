# Acme Fleet Portal (LyteNyte)

**[Live demo →](https://acme-portal-lytenyte.vercel.app)**

An exotic sports car dealer portal built as an [Autodevelop](https://github.com/devprecated/autodevelop) demo. Grids use [LyteNyte](https://www.1771technologies.com/). Data is mock and held in memory.

Original app: [github.com/devprecated/acme-portal](https://github.com/devrecated/acme-portal) · [acme-portal-five.vercel.app](https://acme-portal-five.vercel.app)

## Rewrite timing with Autodevelop

| What shipped | Agent | Senior engineer |
| --- | --- | --- |
| Create LyteNyte | **8 min** | **1–2 days** |
| Fix UI bugs | **4 min** | **1–2 hours** |
| Live on Vercel | **6 min** | **30–60 min** |

**Total: about 18 minutes** vs **1.5–2.5 days**.

Those 18 minutes include running the app and checking it. With Autodevelop, a developer could have spent that same window on other bugs or features.

Learn more about Autodevelop and how to install at [github.com/devprecated/autodevelop](https://github.com/devprecated/autodevelop).

## Run locally

pnpm install
pnpm dev
